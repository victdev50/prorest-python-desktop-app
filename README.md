# ProRest

A desktop wellbeing application built by a team of four, to help people manage
stress and protect their mental health while working.

People skip breaks, and not because they forget breaks exist. They skip them
because stopping feels like falling behind. ProRest takes the decision away: it
runs structured work and rest cycles, and fills the rest periods with music so
the break is something rather than nothing.

## What it does

Five tabs, each a reminder you can turn on and leave alone:

| Tab | What it does |
| --- | --- |
| Breaks | Periodic reminders to stand up and rest your eyes |
| Music | Plays from a database of tracks, in order or shuffled, or on a timer |
| Snacks | Reminders with a rotating recommendation |
| Important dates | Notifies you the day before something you have saved |
| Sleep | Works backwards from your wake-up time to tell you when to go to bed |

Reminders run on background threads so the interface stays responsive while
timers are counting.

## Built test first

Test-driven, with dedicated test modules for the database layer and the core
logic, and a Makefile to run them.

```bash
make test        # lint, then tests with coverage
make coverage    # coverage report and HTML output
make lint        # flake8 and pylint
make bandit      # security scan
make metrics     # radon complexity and maintainability
```

## Setting it up

```bash
python -m venv .venv
. .venv/bin/activate        # Windows: . .venv/Scripts/activate
make install
```

The database is MySQL. Create it and its user from the scripts:

```bash
mysql -u root -p < Mysql/User.sql
mysql -u root -p < "Mysql/Prorest ddl.sql"
```

`Mysql/User.sql` creates a local development account. Connection settings are
read from the environment and fall back to that local account, so it runs after
those two scripts with nothing exported:

| Variable | Default |
| --- | --- |
| `PROREST_DB_USER` | `userPro` |
| `PROREST_DB_PASSWORD` | `pass` |
| `PROREST_DB_HOST` | `127.0.0.1` |
| `PROREST_DB_PORT` | `3306` |
| `PROREST_DB_NAME` | `Prorest` |

Set them for anything that is not a local development machine.

Then:

```bash
python Python/Gui.py
```

## A note on Gui.py

It is long, and most of it is not hand-written. `setupUi` and `retranslateUi` are
**Qt Designer output** generated by `pyuic5`. The hand-written part starts at
`break_press` and is everything below it: the button handlers, the scheduling and
the worker threads.

## My part

## Limitations

Music playback goes through `pafy` and `youtube-dl`, both of which have been
unreliable since YouTube changed its interfaces. That feature is the most likely
one to be broken on any given day, and it is a dependency problem rather than a
design one.
